---
name: grilling
description: Relentlessly grill a plan, decision, or idea. Use when the user asks to stress-test their thinking or uses a grill trigger.
metadata:
  opencode/slash: true
---

Map the subject as a **design tree**. Work in rounds. The **frontier** is every decision whose prerequisites are settled.

Ask every frontier question in one round. Number each question and give a recommendation:

```
❓ **Q1 — <title>**: <question and choices>

➡️ <recommended answer>
```

Wait for answers before the next round. Recompute the frontier each time. Defer questions that depend on another open question.

Find facts yourself. If a fact needs exploration, delegate it and ask the other frontier questions now. The user makes decisions. Finish only when the frontier is empty and the user confirms the shared understanding.
